## 💡 Tips for Better Garage Notes

Clear notes make the toolkit far more useful. Keep names short and consistent, such as “Road Grip A” or “Dirt Launch B.” Use the same event labels each time so the analytics view can group entries correctly. When you change a tuning profile, add a brief line about what changed and how the car felt afterward.

It also helps to keep a few “reference” entries that you rarely edit. A reference build gives you a stable comparison point when you try something new. If a new setup feels worse, you can compare it against the reference entry instead of relying on memory.

## 🗂️ Managing Multiple Cars

The garage grows quickly in Forza Horizon 5, so organization matters. Group cars by purpose rather than by brand or rarity. A road group, a dirt group, and a drift group are easy to understand and easy to search later. Within each group, keep the most-used car at the top of your notes so it is quick to find.

If a car serves more than one purpose, create separate build entries instead of mixing notes. This keeps each setup readable and makes tuning profiles easier to match to the right car. When a car is no longer used, keep the entry but mark it as retired in the notes. The history is often more useful than a clean, empty list.

## 🔄 Keeping Profiles Up to Date

Tuning profiles should change as your driving style changes. Review the profiles you use most and update them after a few sessions. If a profile has not been used in a long time, it can stay in the list as a reference. The toolkit does not need a strictly tidy list. It needs a list you can understand when you come back to it.

When you create a new profile, base it on an existing one and change only one or two details at a time. This makes it easier to tell which change affected the car’s behavior. The tuning section pairs well with race tracking because the results give context to the setup notes.
